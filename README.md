
## Description:
The NBA Salary Predictor is a machine learning project that estimates NBA player salaries based on historical player statistics. Raw datasets were collected from basketballreference.com and hoopshype.com, then cleaned, processed, and analyzed using Python. The project demonstrates end-to-end ML workflow, including data extraction, preprocessing, visualization, and model training and evaluation.

## Features: 
- Extract and aggregated raw player statistics from multiple sources
- Data cleaning, manipulation, and feature engineering using Pandas and NumPy
- Data visualization using Matplotlib and Seaborn to identify trends and correlations
- Random Forest Regression model training using scikit-learn
- Model performance evaluation using Mean Absolute Error (MAE) and Coefficient of Determination (R-squared)

- ## Tech Stack
- **Programming Language:** Python  
- **Data Manipulation:** Pandas, NumPy  
- **Data Visualization:** Matplotlib, Seaborn  
- **Machine Learning:** scikit-learn (Random Forest Regression)  
- **Interface:** Command-Line Interface (CLI) for running predictions and testing the model
